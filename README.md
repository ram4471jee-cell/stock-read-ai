# Stock Read AI – Free MVP

यह एक शुरुआती, मोबाइल-अनुकूल options research dashboard है।

## शामिल सुविधाएँ
- NIFTY, BANKNIFTY, FINNIFTY, SENSEX selector
- Manual CE OI / PE OI और PCR
- ATM strike
- PCR आधारित CALL BIAS / PUT BIAS / NO TRADE
- Black–Scholes Delta, Gamma, Theta और Vega calculator
- PWA manifest और service worker

## महत्वपूर्ण सीमाएँ
- इसमें Dhan API या live market data कनेक्ट नहीं है।
- Max Pain अभी placeholder है; सही Max Pain के लिए सभी strikes का CE/PE OI चाहिए।
- Signals केवल शुरुआती bias हैं, खरीद/बिक्री की सलाह नहीं।
- लाइव डेटा/अलर्ट/बैकएंड अभी शामिल नहीं हैं।

## GitHub Pages
Repository में इन चार फाइलों को root में upload करें। Settings → Pages → Deploy from a branch → main → /(root) → Save चुनें। प्रकाशित HTTPS URL Chrome में खोलें, फिर Chrome menu → Install app / Add to Home screen चुनें।
